# Shelly LED Mode Switch

A Shelly script for cycling LED lamp modes using a Shelly input or virtual button.

## Files

- `shelly-library.json` — custom Shelly Script Library catalog.
- `mode-switch/mode-switch.js` — the Shelly script.

Paste the working script into `mode-switch/mode-switch.js`, then commit and push the files to GitHub.

In the Shelly web UI, configure the Script Library to use the raw-file URL for `shelly-library.json` in this repository.
